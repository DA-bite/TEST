Getting started

Get from an empty GitHub repository to a live site. Most of the work is one setting.

Before you begin

  • A GitHub account and a repository to publish from.
  • Git on your machine.
  • Node 20 or newer, only if you want to preview the site locally. GitHub installs Node itself when the workflow runs.
Use a public repository

GitHub Pages on a private repository needs a paid GitHub plan. On a free account, make the repository public.

Publish the site

  1. Create an empty repository

    On GitHub, create a repository with no README, license or .gitignore. An empty repository means your first push can't conflict with anything.

  2. Push the code

    From the project folder, point Git at your repository and push main.

    git init -b main
git add .
git commit -m "Add site"
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
  3. Switch Pages to GitHub Actions

    In the repository, open Settings, then Pages. Under Build and deployment, set Source to GitHub Actions. This is the step people miss. Until it is set, the workflow fails when it tries to configure Pages.

  4. Run the workflow again if it already failed

    Open the Actions tab, choose the failed run and select Re-run all jobs. You can also push any new commit.

  5. Open the site

    When the run turns green, the deploy job shows the live URL. It follows this pattern:

    https://<user>.github.io/<repo>/

Check the run

Each push creates a run on the Actions tab with two jobs. Build and test produces the site and checks it. Deploy to GitHub Pages publishes it and only starts after the first job passes. If either job fails, open it to read the log. The troubleshooting guide covers the common failures.

Preview locally

Build and serve the site on your machine before you push.

npm start

The page opens at the address printed in the terminal, usually http://localhost:3000. Run npm run check to build and test without starting a server. The site is plain files, so there is no watch mode. Run the build again after you edit a page.

Make your first change

Edit site/index.html, commit and push. A minute or two later the change is live.

git add .
git commit -m "Change the headline"
git push
